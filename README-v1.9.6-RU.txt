DonutVision v1.9.6 — SMART SCHEMATIC PLACE (LITEMATICA)
====================================================

ЧТО ДОБАВЛЕНО

* F12 / Right Shift -> Modules -> Smart Schematic Place.
* При ПРАВОМ КЛИКЕ рядом с голограммой ищет ближайшую ещё не поставленную
  позицию схемы и выбирает подходящий блок из 9 слотов хотбара.
* Если возможно, устанавливает блок, используя обычное взаимодействие
  Minecraft с реально существующим соседним блоком.
* Settings -> Schematic snap radius: 0.75-3.0 блока от места клика.
* Пока помощник включён, случайная установка вне схемы блокируется.

ВАЖНО

1. Для режима нужны Litematica и MaLiLib, совместимые с Minecraft 26.1.2.
2. Схема должна быть не просто открыта как файл, а размещена в мире
   через Litematica (Schematic Placement).
3. Держите нужные строительные блоки в хотбаре.
4. При Smart Schematic Place выключите Easy Place в Litematica, чтобы
   они не конфликтовали друг с другом.
5. Пока поддерживаются только блоки БЕЗ дополнительных свойств
   (например, камень, доски, стекло и многие простые полные блоки).
   Для ступеней, плит, направленных блоков лучше использовать
   Litematica -> Generic -> easyPlaceMode = true, без Smart Place.
6. Помощник исправляет только НЕБОЛЬШОЙ промах (макс. 3 блока).
   Если нажать далеко от схемы, не будет угадывать, куда ставить блок.
7. Требуется доступный соседний простой блок, обычная дальность
   установки и прямая видимость. Сервер может отклонять установку.
8. Это не полностью автоматический строитель и не обход античита.
9. Новый режим при каждом запуске игры выключен — включается вручную.

УСТАНОВКА ЧЕРЕЗ GITHUB

1. Распакуйте DonutVision-v1.9.6-GitHub-update.zip.
2. Перенесите файлы в корень проекта DonutVision-26.1.2,
   сохранив пути src/client/java/dev/donutvision и другие.
3. GitHub -> Commit changes -> Actions -> Run workflow.
4. Из успешной сборки скачайте артефакт JAR, распакуйте ZIP,
   положите .jar в папку mods в Prism Launcher.

ПРОВЕРКА

Полная сборка через Gradle / запуск Minecraft в текущей среде не
выполнялись: требуется Java 25, Fabric 26.1.2 и совместимая Litematica.
Если GitHub Actions даст красный крестик, пришлите ошибки компиляции.
