DonutVision v1.9.9 — Schematic Printer fix (Minecraft Fabric 26.1.2)

ИСПРАВЛЕНО
- В меню Right Shift (или F10) -> Modules: САМЫЙ ПЕРВЫЙ переключатель
  "Schematic Printer" включает / выключает автостроитель. Дополнительно F12.
- Не зависит от Easy Place: читает размещённую схему из виртуального мира Litematica.
- Выбор нужного блока из хотбара 1..9 выполняется независимо от возможности
  поставить блок прямо сейчас.
- Исправлено подавление ПКМ: если Printer выключен или Litematica не предоставляет
  схему, обычное действие ПКМ не перехватывается.
- Действие происходит при удержании ПКМ; наводить прицел на точный блок не нужно.
- Сообщения статуса показывают, почему строительство остановилось.

УСТАНОВКА В GITHUB
1. Открой архив DonutVision-v1.9.9-GitHub-fix.zip.
2. Сохраняя вложенные пути, замени файлы в ПАПКЕ DonutVision-26.1.2 проекта.
3. GitHub -> Commit changes -> Actions -> Build DonutVision -> Run workflow.
4. Скачай JAR из Artifacts удачной сборки. ЗАМЕНИ старый DonutVision JAR
   в mods выбранной сборки Prism Launcher, НЕ оставляй старую копию.

КАК ПОЛЬЗОВАТЬСЯ
1. Установи подходящие для Minecraft 26.1.2 Litematica и MaLiLib.
2. Загрузить *.litematic мало: требуется РАЗМЕСТИТЬ СХЕМУ в мире
   (создать schematic placement, чтобы появилась голограмма).
3. Положи необходимые блоки в хотбар 1..9.
4. Right Shift -> Modules -> Schematic Printer: ON.
5. Выйди из меню и УДЕРЖИВАЙ ПКМ, находясь рядом с голограммой.
6. В случае проблем снова открой меню и посмотри SCHEMATIC PRINTER STATUS.
7. OFF в меню возвращает обычное поведение ПКМ.

ОГРАНИЧЕНИЯ
- Сервер разрешает только обычную дальность установки (около 4.4 блока).
- В выживании нужен уже существующий соседний блок для размещения в воздухе.
- Направление лестниц, плит и ряда специальных блоков пока не гарантируется.
- Мод не использует Litematica Easy Place, но сама Litematica нужна для схемы.
- Полная сборка и запуск на сервере в этой среде не проверялись.
